# H3 Eight-Direction Actions

以已审定的 4 列 × 2 行八方向 idle 图作为 `<Picture 1>`，编写用户要求的 STAND、RUN、ATTACK、MAGIC、DIE 或 HIT 英文提示词。用户只要 RUN 时，只交付 RUN。每段视频同时保留同一角色的八个方向，八格同步表演同一动作；格位与朝向取自参考图。

## 输入与生成入口

- 已有八方向图时，以它为布局、造型、尺度和各格朝向的权威参考。动作姿势可以变化，角色的水平朝向仍须保留。原始角色设计图仅用于核对细节。
- 仅有原始设计图时，先使用可用的 `character-45deg-idle-turnaround` 技能制作八方向图或其提示词；朝向审定后再写动作，不把尚未生成的图称为 `<Picture 1>`。
- 读取图像，提取画风、服装、非对称特征、左右持物和道具数量。攻击方法不明时简短询问，不虚构武器；施法可利用已有特征，不添加未经要求的常驻装备。
- 从会话确认使用海螺网页、官方 API、第三方入口还是本地 ComfyUI，复用用户已经提供的信息。尚不明确时可先写动作文本，暂不猜测具体时长和分辨率。
- 用户明确指定的动作、风格和背景优先。背景默认沿用 idle 图；需标准化成纯绿时明确说明，常用值为 `#00FF00`。绿色配饰与背景接近时提醒抠像需保护前景，不默改参考图。

## 八格朝向

在 `subject_definitions` 中完整定义 `<Subject 1>` 至 `<Subject 8>`，均来自 `<Picture 1>` 的对应格：

| Subject | 位置 | 参考名称 | 画面朝向 |
| --- | --- | --- | --- |
| 1 | 上排第 1 格 | FRONT | 正下 |
| 2 | 上排第 2 格 | FRONT-RIGHT | 左下 |
| 3 | 上排第 3 格 | RIGHT | 正左 |
| 4 | 上排第 4 格 | BACK-RIGHT | 左上 |
| 5 | 下排第 1 格 | BACK | 正上 |
| 6 | 下排第 2 格 | BACK-LEFT | 右上 |
| 7 | 下排第 3 格 | LEFT | 正右 |
| 8 | 下排第 4 格 | FRONT-LEFT | 右下 |

画面朝向和各格原图优先于英文名称；实际英文提示词优先使用 `image lower-left` 等屏幕方向，避免角色左右与画面左右混淆。第 2/8 格保留各自不同的正面三分之四视图，第 4/6 格保留各自背面三分之四视图；不通过水平镜像替代非对称角色的旋转。

镜头俯角与角色自身的水平朝向是两个约束。固定 45 度俯角还须配合逐格朝向保持；不要用含混的 `45-degree yaw identity` 代替各格参考视角。四个斜向应绑定原图中实际可见的脸部、头部轮廓、肩膀遮挡、胸部或背部宽度，不能仅写 `keep the angle`。

## 提示词结构与长度

先读 [references/action-blocks.md](references/action-blocks.md)，按用户所需动作组装完整提示词。写 RUN 或处理倒跑、斜向转侧面时，还须读 [references/run-direction-lock.md](references/run-direction-lock.md)。

六段字段依次为：`subject_definitions`、`summary`、`retention_analysis`、`detailed_description`、`overall_soundscape`、`non_diegetic_music`。只有一个实际镜头段落 `[Shot 1]`；保留分析中可以引用该镜头。默认不加时间戳、不切镜。八个视图整段可见，避免 `single character` 或 `only one character`。

### 在线文本长度是交付前的必检项

- 海螺/官方 API 已确认的上限为每段提示词 **7000 字符**；第三方入口可能更低，按实际限制处理。通常以 4500–6000 字符为写作预算，留出换行与平台包装余量，这个预算是建议值。
- 对最终准备粘贴的完整正文实际计数，包含字段名、标签、空格和换行；不凭词数或 token 数估计。每次改写后重新计数，超过限制先压缩再交付。只测骨架长度不能代替成稿检查。
- 优先使用 [scripts/check_prompt.py](scripts/check_prompt.py)：`python scripts/check_prompt.py <prompt.txt>`。也可用等价代码计数；没有执行计数时不得声称“已核验字符数”。长度合格不等于已通过生成或动作验收。
- 完整替换旧文本，避免把修订段追加到旧版后造成超长。写清参考映射和动作一次即可；优先删重复服装、光线、背景和抽象保证，保留关键朝向与步态信息。
- `invalid params` 先读完整错误中的字段和原因。例如 `content[0].text too long: 7960 > 7000 characters (2013)` 已明确指向文本超长。不能仅凭错误码 2013 推断认证或图片问题；只有通用错误时先获取详细字段，不猜根因。

## 通用画面与动作要求

- 镜头写一次：`a static shot at a fixed 45-degree orthographic top-down game angle, flat orthographic projection at a constant zoom level`。按参考保持约 4.5 头身；不靠变焦修正比例。
- 保持 4×2 布局、统一角色尺度和导出格原点。地面锚点指原地动画的参考原点，RUN 的脚仍需完成支撑与回收。全身可见面积目标为单格的 18%–25%，上限 30%，动作可用周围留白；这是制作目标，未经测量不声称现图已满足，也不擅自重排已审定的图。
- 中性顶部光、脚底下方紧凑接触阴影、平坦纯色背景。头发、肢体、道具和特效全程留在各自格内。
- 用肯定句描述所需布局、方向和动作，不堆叠负面词。只有所用本地 BasicGuider 已确认无负面输入时才据此处理；不要把本地节点特性当作网页/API 的统一接口规范。
- 逐视图明确道具归属、数量与解剖学左右手，屏幕位置随各格透视决定。DIE 中如需脱手，道具落在对应角色旁并在尾帧保持可辨。只描述参考里实际存在的装备。
- STAND 全片周期呼吸，双脚和膝盖稳定。RUN 原地完整步态循环，首尾相位匹配；保持首帧朝向不等于要求 RUN 从长时间站立开始。ATTACK、MAGIC、HIT 有预备、动作和恢复，并回到各自首姿；DIE 连续倒地一次，尾帧静止。
- `overall_soundscape` 使用对应的轻微拟音，无对白；`non_diegetic_music` 为 `N/A`。不用 `(S1)` 或 `<d>`。

## 时长与分辨率按入口区分

| 入口 | 时长 | 分辨率 |
| --- | --- | --- |
| 海螺网页 | 用界面实际提供的秒数 | 用界面实际支持的规格 |
| 官方 API | `duration` 是秒；本次核查为 4–15 的整数，参数变化时重查官方文档 | 用该模型与模式支持的规格，不把输入图片尺寸当输出尺寸 |
| 第三方平台 | 按其字段、单位与限制 | 按其实际支持的规格 |
| 本地 H3 工作流 | 仅在节点明确使用帧数且要求 `17k+5` 时，采用下表 | 仅在节点有该要求时约束 32 倍数；512×512 是部分旧工作流测试值 |

本地兼容默认：STAND/RUN/ATTACK/MAGIC 39 帧，DIE 56 帧，HIT 22 帧。只在确认帧数规则适用时，把不合规数值上取整并告知。不得把 39 填入在线 `duration`，也不把本地帧数、32 倍数或 512×512 建议强加给在线入口。保留已跑通的参数有助于单独检查提示词修改效果。

官方限制参考：[MiniMax CLI 的 H3 参数说明](https://github.com/MiniMax-AI/cli/blob/main/skill/h3-video/SKILL.md#core-limits)。以上在线信息核查于 2026-10-22；使用入口已有明确规则时以实际规则为准。

## 根据测试反馈迭代

- 分别记录“请求能提交”“动作相位稳定”“步态正确”“斜向保持”是否经用户测试；一个方面改善不代表其他方面已解决。
- 倒跑先检查各格支撑脚与离地腿的运动顺序和地面方向。斜向漂移优先限制躯干转动、绑定可见外观；强约束的固定视图 2D 骨架方案是可测试的修订策略，不是已验证的保证。
- 同类漂移经针对性修订仍重复时，建议改变参考或制作流程：保留合格方向，逐方向裁图生成，必要时先准备朝向正确的 RUN 关键帧，再按相位合成。不无限追加约束、不宣称继续加字必能固定角度；用户坚持整图方案时继续在该范围内优化并说明局限。
- 有失败帧或视频时据此判断是头部、躯干还是整体朝向变化；材料未提供时，把原因判断标为推测，不妨碍先给出可检验修订。

## 交付与验收

每个请求动作各交付一个完整六段英文代码块，标题按入口标注在线秒数/支持规格，或本地帧数/分辨率；未知参数沿用用户已成功设置，不编造。报告实际测得的字符数，说明完整替换旧版。不要把公共模板引用或未替换占位符交给用户。

检查八格、八朝向、同步相位、道具归属及格内边界。RUN 额外检查背面步态和第 2/4/6/8 格的参考外观；STAND/RUN 循环接缝平顺；DIE 只落地一次且道具存续。提示词约束不能称为已验证的渲染结果。

按需要简述去背景、统一调色板、相位抽帧与最近邻降采样；抠像保护接近背景色的角色配饰。逐方向合成也须保留各自原图、统一尺度和格原点，不把镜像视为等价旋转。
